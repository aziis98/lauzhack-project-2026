**Optimization.** Among all rectangles inscribed in a semicircle of radius $r = 1$, with the base lying on the diameter, find the one with the **largest area**.

1. Call $x \in (0, 1)$ half of the base. Show that the height is $h = \sqrt{1 - x^2}$.
2. Write the area as a function $A(x)$.
3. Study $A'(x)$ and find the maximum of $A$ on $(0, 1)$.
4. What is the maximum area? What is the ratio between base and height?
